# Retail Sales Data Analysis

A beginner-friendly data analytics project analyzing retail sales data using Excel, SQL, and Power BI.

## 📊 Dashboard

![Retail Sales Dashboard](Retail%20Sales%20Dashboard.png)

## 📌 Project Overview

This project analyzes a synthetic retail sales dataset to identify sales trends, top-performing products, categories, and regions.

The project was created as a practical learning project to build hands-on skills in data analysis and business intelligence.

## 🛠️ Tools Used

- Excel
- MySQL
- Power BI
- GitHub

## 📂 Dataset

The dataset contains 100 retail orders with the following fields:

- Order ID
- Order Date
- Product
- Category
- Quantity
- Unit Price
- Sales
- Region

## 📈 Key Insights

- Total Sales: **36,144.26**
- Total Orders: **100**
- Total Units Sold: **292**
- Top Product by Sales: **Laptop**
- Top Category by Sales: **Electronics**
- Top Region by Sales: **North**
- Highest Sales Month: **April**
- Average Order Value: **361.44**

## 🔍 Analysis Performed

### Excel
- Sales calculations
- Pivot tables
- Monthly sales analysis
- Product, category, and region analysis

### SQL
- Aggregations using `SUM()` and `AVG()`
- Filtering using `WHERE`
- Grouping using `GROUP BY`
- Sorting using `ORDER BY`
- Filtering grouped results using `HAVING`
- Monthly sales analysis

### Power BI
- KPI cards
- Sales by region
- Sales by category
- Sales by product
- Monthly sales trend
- Interactive Region and Category filters

## 💡 Business Insights

1. Laptops generated the highest sales among products.
2. Electronics was the highest-performing category by sales.
3. The North region generated the highest sales.
4. April recorded the highest monthly sales.
5. The average order value was 361.44.

## 🎯 Project Goal

The goal of this project was to practice the complete data analysis workflow:

**Excel → SQL → Power BI → Business Insights**
